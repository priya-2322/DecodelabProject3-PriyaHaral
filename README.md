# DecodelabProject3-

This project demonstrates how to deploy an application on an AWS EC2 instance and connect it to an Amazon RDS MySQL database.

The main objective of this project is to understand how EC2 and RDS can be used together to host an application and manage its database separately.

🛠️ Technologies Used
AWS EC2
Amazon RDS
MySQL
Linux
Git & GitHub
1. Launch EC2 Instance
Create an EC2 instance on AWS.
Connect to the instance using SSH.
Install the required packages and dependencies.
2. Create RDS MySQL Database
Create an Amazon RDS MySQL database.
Configure the required database settings.
Configure security groups to allow the EC2 instance to communicate with RDS.
